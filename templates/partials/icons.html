{# Shared inline icons. Inline SVG rather than an emoji or an icon font: it inherits the button's colour via currentColor, stays crisp at any size, and needs no external request (the app is served without a CDN for anything but Chart.js). Icon-only buttons carry both title and aria-label so the action is still announced to a screen reader and on hover. #} {# A door with an arrow leaving it. Sits beside the "Sign out" label rather than replacing it: ending the session by mis-clicking an unlabelled glyph is a worse mistake than the space the word costs. #} {% macro sign_out() %} {% endmacro %} {% macro search_button(label='Search') %} {% endmacro %} {# A tick, for marking an order delivered. Secondary styling keeps it visually apart from the red bin sitting next to it, so the two are told apart by colour as well as shape. Unlike Delete this asks for no confirmation, so the label naming the order matters more than usual — it is the only warning before the click lands. #} {% macro deliver_button(label='Mark delivered') %} {% endmacro %} {# A waste bin. Pass a label naming the record — "Delete Priya Sharma" rather than a bare "Delete" — because a list shows one of these per row, and identical labels leave a screen reader unable to tell them apart.
